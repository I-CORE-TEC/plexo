# Gestión manual de novedades (retirada)

La pantalla de Novedades y su versión dentro de Derechos se retiraron por la simplificación del #219. El flujo vigente es [Padrón mensual de OSTEL](padron-mensual-ostel.md).

- Los enlaces antiguos a `/financiadores/novedades` llevan al historial de la persona en el padrón, o al padrón si no hay persona.
- Los registros existentes no se migran. En el historial del padrón siguen visibles como «Origen: Novedad del financiador · Novedad #N», sin enlace.
- La API de novedades del backend no cambió. No hay pantallas nuevas que la usen.

La descripción anterior de esta pantalla está en el historial de git de este archivo.
