    Planilla de Estimación de Horas

    Plantilla

    Estimación formal de un requerimiento. Se presenta como rango (mínimo / máximo) para contemplar variabilidad. La aprobación llega por email desde una casilla oficial de OSTEL y el PM deja constancia en el Issue antes de iniciar el desarrollo.

    Metadatos

    Campo Valor
    Proyecto OSTEL — Implementación de PLEXO
    Issue #<número> — Título del requerimiento
    Fecha de estimación YYYY-MM-DD
    Estimado por Nombre del estimador

    Descripción del requerimiento

    Resumen breve del requerimiento a estimar.

    Desglose por etapa

    Etapa Horas mín. Horas máx. Notas
    Análisis N N Observaciones
    Documentación N N Observaciones
    Desarrollo N N Observaciones
    Pruebas N N Observaciones
    Capacitación N N Solo si aplica
    Despliegue N N Observaciones
    TOTAL N N

    Supuestos y condiciones

    Si alguno cambia, la estimación puede variar

    • El entorno de pruebas está disponible y funcionando.
    • No hay cambios de alcance durante el desarrollo.
    • La documentación de origen necesaria fue entregada por OSTEL.
    • OSTEL responde consultas dentro de los plazos acordados (ver Metodología).
    • Agregar otros supuestos

    Riesgos que pueden impactar la estimación

    Riesgo Probabilidad Impacto estimado
    Riesgo Alta / Media / Baja +N hs

    Saldo de horas del cliente

    Concepto Valor
    Saldo actual N hs (a validar con el PM antes de confirmar)
    Horas requeridas (rango) N – N hs
    ¿Saldo suficiente? Sí / No — si no, indicar qué hacer

    Aprobación del cliente

    Constancia de aprobación

    La estimación fue presentada y aprobada por:

    • Nombre: Referente institucional de OSTEL
    • Fecha de aprobación: YYYY-MM-DD
    • Medio: Email desde casilla oficial (asunto y fecha)

    Antes de iniciar el desarrollo

    Contar con el email de aprobación de OSTEL y dejar constancia en el issue #N (fecha, remitente y asunto).
